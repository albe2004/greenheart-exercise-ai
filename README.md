# greenheart-exercise-ai
🛠️ Struttura del Codice
Il progetto è sviluppato in HTML e CSS e segue le migliori pratiche di design:

Flexbox / Grid per un layout responsive

Palette colori naturali (verde, blu) per trasmettere un tema eco-friendly

Media queries per garantire la leggibilità su dispositivi mobili

Animazioni CSS per migliorare l'interazione utente

🔧 Installazione e Utilizzo
Per visualizzare il progetto:

Scarica i file HTML e CSS

Apri il file index.html con il tuo browser

Modifica style.css per personalizzare il design
